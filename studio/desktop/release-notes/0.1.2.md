## What's new in 0.1.2

- **Smooth slow motion.** Below 1x, or for a 30 fps file in a 60 fps project, the editor blends the two source frames
  around each frame instead of showing one frame twice (Properties › Video › Motion blur › Smooth slow motion).
- **Instagram Reel export preset.** H.264 MP4 at the project's frame rate: 1440×2560 at 25 Mbps for a 2K vertical
  project at 60 fps, otherwise 1080×1920.
- **Speed ramps fixed.** A speed curve on a clip cut from the middle of its file no longer jumps to the file's start.
- **For AI agents (MCP):** add a look from a computed `.cube` (`looks.add`), list the export presets
  (`export.presets`), give keyframes custom bezier or spring easing, and keyframe the size of 2K and 4K clips.
- **A guide page for drone footage** (Docs › Drone footage): stabilization, colour, speed and motion blur, export.
- The web editor opens straight on its projects and points to the desktop app; the Licenses link moved to the docs.
