## What's new in 0.1.4

- **DroneClean Studio for Windows.** A per-user installer for Windows 10 and 11 (x64), `DroneClean-Studio-x64.exe`,
  not signed yet: SmartScreen asks once, choose More info › Run anyway. It carries its own FFmpeg with NVIDIA NVENC,
  Intel Quick Sync and AMD AMF, so exports use the graphics card's encoder, and it runs WebGPU on the discrete card
  of a PC that also has integrated graphics.
- **Framing keyframes.** The stabilized window's Framing can move over the clip, with a diamond beside each slider,
  so a 9:16 edit can follow its subject.
- **AAC from iTunes-style files.** Audio whose encoder delay is written only in an iTunes tag now starts on time (it
  was 21 ms late).
- **For AI agents (MCP):** `run` saves the project after every call that changed it (its result says `saved`), and
  a reload of a stuck or crashed editor opens the agent's project again, so nothing an agent did is lost. The MCP
  starts when the app is reached through a symlinked folder (it used to close the connection without a word), and
  its instructions walk an agent through a drone edit: clips end to end, stabilization, a title, a before and after,
  the export presets.
