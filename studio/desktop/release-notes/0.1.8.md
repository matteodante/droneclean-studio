## What's new in 0.1.8

- **Shadow removal shows its price before it runs.** A preview and following the shadow now use credits, and the
  buttons say how many. You are never charged more than the price you agreed to, and if no shadow is found where
  you clicked, the credits come back. New accounts start with 600 credits. Earlier versions can still export, but
  for previews and following the shadow they ask you to update.
- **Smoother first playback.** Stabilized clips no longer stop at each cut the first time an edit plays: Studio
  prepares the next clip's stabilization a second ahead.
- **No error flash during playback.** The motion blur no longer shows a "could not be decoded" card for an instant
  while the preview rebuilds.
- **Iris and Clock Wipe fill the frame.** No more band of stretched edge pixels on full-frame clips, as Fade in
  0.1.7.
- **Crash reports, if you want them.** At first launch Studio asks whether it may send crash reports. Nothing is
  sent unless you say yes, and Settings › Privacy changes your answer at any time.
- **AI agents.** `frame` with a contact sheet and `full` writes the sheet to the project's frames folder, title
  colours accept `rgba(...)`, and following the shadow needs its price, so an agent never spends credits unseen.
