## What's new in 0.1.5

- **AI agents work out of the box.** Settings › Agent access › Allow AI agents is now on by default: an agent on your
  computer (Claude Code, Codex or any MCP client) connects without a trip to Settings first. Only programs running
  under your user account can reach it, nothing listens on the network, and if you switch it off it stays off.
- **Stabilized clips play smoothly in the preview.** Playing a stabilized clip no longer stops on "waiting for
  stabilization…" or shows a frame unstabilized and then again: each frame's correction is read ahead of the
  playhead, the first frames after a cut are asked for before the cut arrives, and a correction a few milliseconds
  away is waited for instead of holding the previous picture. On a 56-second reel of twelve stabilized clips
  (1440x2560 at 59.94 fps, seven of them sped up 1.2-2.5x) the message showed for a quarter of a 10-second stretch
  before; played twice from the start, it no longer appears. It also shows only for the clip under the playhead.
- **For AI agents (MCP):** a title asked for over a clip is refused with the first free frame (it used to land after
  the last clip without a word); search hits carry the SDK's whole declarations; a script that fails partway says
  which edits it kept; opening another project no longer lists both timelines entry by entry; a finished export
  names its file on disk (`absolutePath`); and the instructions walk an agent through a title on its own track and a
  before and after that fills the frame.
- **A workspace folder that is gone no longer locks you out.** If the folder the app remembers was moved, renamed or
  deleted, it now asks for a folder and names the old one; it used to say "This folder is open in another DroneClean
  Studio window" with only Close, at every launch. When another window really holds a folder, that message now offers
  **Choose another folder** too.
