# Changes to FreeCut's own files

DroneClean Studio is a fork of [FreeCut](https://github.com/walterlow/freecut) that is kept mergeable with it
(`upstream-studio/main`). New code lives in new folders; a file that FreeCut owns gets the smallest hook that does the job,
and every such file is listed here with the reason. When a merge of upstream conflicts in one of them, this table
says what our side of the conflict is for. Add a row in the same commit that touches the file.

Since 18 Nov 2026 the fork is the folder `studio/` of the branch `editor` of `matteodante/droneclean`, added with
`git subtree add` from the branch `studio/main` (full history). Upstream is merged with
`git subtree merge --prefix=studio upstream-studio/main`. FreeCut's git hooks (`.vite-hooks/`) and its workflow
(`.github/workflows/ci.yml`) are left exactly as upstream has them and do nothing in this position: git and GitHub
read hooks and workflows at the repository's root only.
